Materi Dasar Komputasi Awan

1. Pengertian Komputasi Awan (Cloud Computing)

Komputasi awan adalah model penyediaan sumber daya komputasi (seperti server, penyimpanan, basis data, jaringan, dan perangkat lunak) melalui internet secara on-demand. Pengguna dapat mengakses layanan ini kapan saja dan dari mana saja tanpa perlu mengelola infrastruktur fisik secara langsung.

2. Model Layanan Cloud

Software as a Service (SaaS)

Layanan perangkat lunak siap pakai yang berjalan di atas infrastruktur cloud dan diakses melalui browser atau aplikasi. Pengguna tidak perlu memikirkan instalasi maupun pemeliharaan server. Contoh: Google Drive, Gmail, Microsoft 365.

Platform as a Service (PaaS)

Layanan yang menyediakan lingkungan (platform) bagi pengembang untuk membangun, menguji, dan men-deploy aplikasi tanpa harus mengurus konfigurasi sistem operasi atau perangkat keras di baliknya. Contoh: GitHub Pages, Heroku, Google App Engine.

Infrastructure as a Service (IaaS)

Layanan penyewaan infrastruktur IT dasar seperti server virtual (VM), ruang penyimpanan, dan jaringan. Pengguna memiliki kendali penuh atas sistem operasi dan aplikasi yang dipasang di dalamnya. Contoh: Amazon EC2, Google Compute Engine, DigitalOcean.

3. Manfaat dan Risiko Penggunaan Cloud

Manfaat: Efisiensi biaya (tidak perlu beli server fisik), skalabilitas tinggi, aksesibilitas fleksibel dari berbagai perangkat, serta kemudahan kolaborasi dan pencadangan data.

Risiko: Ketergantungan penuh pada koneksi internet, potensi kerentanan keamanan atau kebocoran data jika konfigurasi privasi salah, serta keterbatasan kendali atas infrastruktur fisik penyedia layanan.
